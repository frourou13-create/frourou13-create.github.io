1. Who we are

Agence Publication is a private desktop application used only by its owner, Fedi Rourou (contact: frourou13@gmail.com), to publish his own videos on his own YouTube channels.

2. YouTube API Services

This application uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

3. Information accessed, collected and used

After explicit consent through Google OAuth, the application accesses only the owner's own YouTube channels:

  • basic channel information (channel ID and name) to identify where each video is published;
  • the videos uploaded by the application: title, description, tags, category, language, publication time, thumbnail and subtitles;
  • public statistics (views, likes, comments) of the owner's own videos, read once a day to compare formats.

The application does not access, collect or store any data about other channels, other users or viewers.

4. Storage and sharing

OAuth access tokens are stored only on the owner's computer, encrypted with Windows data protection. All data stays on that computer. Nothing is sent to third-party servers, sold, shared, or used for advertising. The application does not use cookies or any tracking technology.

5. Deletion and revocation

Access can be revoked at any time from the Google account security settings: https://myaccount.google.com/permissions. When a channel is removed from the application (« retirer »), its stored token and pending data are deleted immediately. Stored statistics are deleted within 30 days at the latest, and on request at any time by email to frourou13@gmail.com.

6. Changes and contact

Any change to this policy is published on this page with a new date. Questions: frourou13@gmail.com.
